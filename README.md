# ブラウザで遊べるノベルゲーム2本

Built with Claude: Japan 2026 に出したノベルゲーム2本の、ブラウザ版（v1.1）です。

- 入口：https://fwaohaoi1g168.github.io/novel-web/
- 漢はコーデで語れ：https://fwaohaoi1g168.github.io/novel-web/game1/
- 箱入り娘のナンパ大作戦：https://fwaohaoi1g168.github.io/novel-web/game2/

どちらもティラノスクリプト v6.03 で動きます。2本目は、もとは Ren'Py で作ったものを、ブラウザで軽く遊べるようにティラノスクリプトに移しました。

もとのリポジトリ（ハッカソンに出したもの）：

- [game1](https://github.com/fwaohaoi1g168/game1)（漢はコーデで語れ）
- [game2](https://github.com/fwaohaoi1g168/game2)（箱入り娘のナンパ大作戦。Ren'Py 版）
